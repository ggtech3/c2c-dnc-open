# Unverified starter profiles

These 15 settings files are **Not confirmed** starting points for C2C DNC
`0.9.8-open-preview.2`. They are not bundled or installed automatically.
A matching controller name does not establish compatibility. Review all
parameters, adapter/driver, cable wiring, framing and supported protocols.

## Download and import

1. Open one of the JSON links below. On GitHub choose **Download raw file**,
   or open **Raw** and save the raw contents with a `.json` extension.
   Save the JSON, not the GitHub web page or an HTML file.
2. In C2C DNC choose **Community configurations** > **Import contribution file**.
3. Select the downloaded `.json` and review the complete settings and cautions.
4. Enter your own local profile name and COM port, then explicitly choose
   **Add profile**. Cancel leaves existing profiles unchanged.

Public repository downloads need no GitHub account. Importing and using a
downloaded file need no account, Git installation or internet connection.
GitHub requires an account only if you choose to post an issue or contribution.
Import does not open a serial port, send a program or validate a machine.
