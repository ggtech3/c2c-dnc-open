# Project governance

The repository owner is the maintainer and decision maker during private review. The maintainer controls project scope, review and release decisions, licensing, collaborator access and any future public release.

Changes should normally arrive through a focused branch and draft pull request, with a specification where appropriate, tests and review evidence. The maintainer resolves design disagreements after considering alternatives and user impact. Significant machine/serial changes require explicit scope and independent review where available.

No contributor permissions, automatic merge policy or branch-protection guarantee is implied by this document. Repository settings must be verified separately. Outside contribution terms and an open-source license remain owner decisions before public release.
